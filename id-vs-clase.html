Entendiendo id vs clase en CSS

Octubre 2026

Tabla de contenido Introducción La Clase (class) El Identificador (id) ¿Quién gana la pelea?

Cuando empecé a maquetar mis primeros proyectos, le ponía id a todo o class a todo sin saber realmente la diferencia. Hasta que mi CSS se volvió un desastre y no entendía por qué unos estilos no se aplicaban. Aquí te explico lo que me costó entender, con un ejemplo súper práctico.

La Clase (class) = El Uniforme

Piensa en las clases como un uniforme de la universidad. Muchos estudiantes pueden usar exactamente el mismo uniforme. En HTML y CSS, usamos una clase cuando queremos que varios elementos compartan el mismo estilo. En CSS se seleccionan poniendo un punto . al principio.

Por ejemplo, si tienes varios botones que deben verse igual:

<!-- Varios elementos pueden tener la misma clase -->
<button class="btn-primario">Aceptar</button>
<button class="btn-primario">Enviar</button>
<button class="btn-primario">Descargar</button>
/* Se selecciona con un punto (.) */
.btn-primario {
  background-color: #742977;
  color: white;
  border-radius: 8px;
}

El Identificador (id) = Tu Matrícula

Por otro lado, el id es como tu número de matrícula o tu INE. Es único e irrepetible. Ningún otro elemento en toda tu página debería tener el mismo id. En CSS se seleccionan usando el símbolo de gato o hashtag #.

Se utiliza para partes estructurales únicas (como una barra de navegación principal) o cuando necesitas que JavaScript encuentre un elemento específico de inmediato.

<!-- Solo debe existir un elemento con este id en toda la página -->
<nav id="menu-principal">
  <!-- Enlaces del menú -->
</nav>
/* Se selecciona con un hashtag (#) */
#menu-principal {
  border-bottom: 1px solid #34322f;
  position: sticky;
}

¿Quién gana la pelea? (Especificidad)

Aquí es donde las cosas fallan cuando vas empezando. ¿Qué pasa si un elemento tiene tanto un id como una class, y ambos intentan cambiar el color de fondo a un color distinto?

El id siempre gana. En CSS, los identificadores tienen un "peso" mayor que las clases. Por esta razón, la buena práctica actual es usar clases para casi todos tus estilos, y dejar los id exclusivamente para enlaces ancla (como los de la tabla de contenido) o para manipular el DOM con JavaScript.
